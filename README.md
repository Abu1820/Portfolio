# 🌌 Abdul Majeed R — 3D Interactive Developer Portfolio

An immersive, responsive, and performance-optimized 3D developer portfolio built with **React 19**, **Three.js**, **@react-three/fiber**, **Framer Motion**, and **Tailwind CSS**. Deployed live on Vercel.

🔗 **Live Production Site:** [https://portfolio-abd-e3cd.vercel.app](https://portfolio-abd-e3cd.vercel.app)  
📄 **ATS-Optimized Resume:** [https://portfolio-abd-e3cd.vercel.app/resume.html](https://portfolio-abd-e3cd.vercel.app/resume.html)

---

## 🚀 Key Features

* **3D Interactive Graphics:** Dynamic Three.js desktop computer workstation, 3D rotating planetary Earth canvas, and custom floating 3D tech balls.
* **Hero Experience:** Dynamic typewriter role rotation, live animated metrics counter strip, and instant CTA links.
* **Algorithmic Showcase:** Interactive LeetCode topic distribution meters and competitive programming contest achievements (400+ problems solved, CIT 1st Prize, IEEE 2nd Prize).
* **Project Cards with 3D Spotlight:** Radial cursor-following glow, smooth image zoom, live production indicators (`Uniora`, `CivicPulse`), and interactive quick-inspect modals.
* **Publications Showcase:** 3D Tilt card showcasing authored publication *"Mastering Recommendation Systems"* with direct Amazon Kindle integration.
* **Accessible & Responsive:** Fully optimized layout across mobile, tablet, and desktop viewports with a glassmorphism navbar, top gradient scroll progress bar, and floating rocket back-to-top button.

---

## 🛠️ Tech Stack

* **Frontend:** React 19, TypeScript, Vite, Tailwind CSS
* **3D & Animations:** Three.js, @react-three/fiber, @react-three/drei, Framer Motion, react-tilt
* **Deployment:** Vercel (CI/CD via GitHub)
* **Backend Proficiency Highlighted:** Java, Spring Boot 3, MySQL, Hibernate/JPA, REST APIs, Cloudflare Workers, Supabase

## 📂 Project Structure

```
PORTFOLIO_1/
├── public/                 # Static assets, 3D GLTF models, favicons, resume.html
├── src/
│   ├── assets/             # Tech icons, project banners, company badges
│   ├── components/         # Modular React components (Hero, About, Tech, Works, etc.)
│   ├── constants/          # Site data, projects, experiences, achievements
│   ├── hoc/                # SectionWrapper higher-order components
│   ├── hooks/              # Custom React hooks (in-view, WebGL detection)
│   ├── styles.ts           # Shared typography and layout classes
│   └── app.tsx             # Main application orchestrator
├── vercel.json             # Vercel deployment configuration
└── vite.config.ts          # Vite build config
```

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Abu1820/Portfolio.git

# Navigate into the project
cd Portfolio

# Install dependencies
npm install --legacy-peer-deps

# Start local development server
npm run dev
```
